# Hero Animation Frames

Place your 240 JPEG animation frames in this folder: `public/hero-frames/`

## Naming Format
The files should be named sequentially from `001.jpg` to `240.jpg`:
- `001.jpg`
- `002.jpg`
- ...
- `099.jpg`
- `100.jpg`
- ...
- `240.jpg`

Dimensions: 1280x720 (16:9 ratio) JPEG images.
